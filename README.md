# NULL-MODEM

ブラウザで動くソフトウェアモデムです (300 / 1200 / 2400bps、MNP5)。本物のモデムと同じように音を鳴らしながら、パソコン通信の BBS ([null-bbs](https://github.com/GOROman/null-bbs)) につなぎます。

- 端末で `ATDT0` と打つと、ダイヤルトーン → ダイヤル音 (DTMF) → 呼び出し音 (3 回) → 応答音 (2100Hz) → ハンドシェイク → `CONNECT 1200` と進みます
- 速度を選べます

  | 速度 | 方式 | 1 秒あたりの文字数 |
  |---|---|---|
  | 300bps | V.21 (FSK) | 約 30 |
  | 1200bps | V.22 (DPSK) | 約 120 |
  | 2400bps | V.22bis (16QAM) | 約 240 |
  | 2400bps MNP5 | V.22bis + MNP (同期転送 + 圧縮) | 文章なら 300 以上 |

- 接続後に送受信するデータは、**選んだ方式で実際に変調した音**として鳴ります。当時の「ピーガー」「ザー」と同じ音です
- 音は電話回線を通したように加工します (300Hz〜3.4kHz の帯域、8kHz・μ-law 8 ビット、回線の雑音、送受信の回り込み)
- 受話器を上げ下ろしする「ガチャ」の音、回線が切れる前に文字が化ける演出があります
- **XMODEM** でファイルを送受信できます (転送もモデムの速さで行われます)
- **ステレオで、左 (L) が送信 (発信側キャリア 1200Hz)、右 (R) が受信 (応答側キャリア 2400Hz)** です。全二重なので両方が同時に鳴ります
- データは音にし終えた順に届くので、本当に 1200bps (1 秒に約 120 文字) の速さで表示されます
- Hayes 互換の AT コマンド (`ATDT` `ATH` `+++` `ATO` `ATM` `ATL` `ATI` `A/` など) で操作します
- 送受信の波形と、モデム前面のランプ (HS / CD / OH / RD / SD / TR / MR) を表示します

## しくみ

```
ブラウザ (null-modem)                         自宅の PC
┌───────────────────────┐   WebSocket    ┌────────────────┐    ┌──────────┐
│ xterm.js  AT コマンド │ ─────────────→ │ Cloudflare     │ →  │ null-bbs │
│ AudioWorklet (V.22)   │   (wss://)     │ Tunnel         │    │ (WS 回線) │
│  L: 送信 1200Hz       │ ←───────────── │ (cloudflared)  │ ←  │          │
│  R: 受信 2400Hz       │                └────────────────┘    └──────────┘
└───────────────────────┘
   Cloudflare Workers から配信
```

データそのものは WebSocket で運び、送受信のバイトを V.22 で変調した音を鳴らしながら、その速さで相手に渡します。

## 開発

```sh
npm test          # 変調器 (V.21 / V.22 / V.22bis) と XMODEM のテスト
npx wrangler dev  # 手元で動かす (http://localhost:8787)
```

手元で試すときは、`.dev.vars` に電話帳を書きます。

```
PHONEBOOK=[{"number":"0","name":"TEST-BBS","url":"ws://127.0.0.1:5657/"}]
```
